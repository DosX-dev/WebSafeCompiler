# Сверка с первоначальным компилятором

База сравнения: `c1e7e02` (`source/wsc.js` до исправлений). Реализация остаётся в одном `source/wsc.js`; зависимости устанавливаются через npm.

| Возможность первоначальной версии | Текущая реализация и проверка |
| --- | --- |
| Обычная сборка и DRM | Все четыре сочетания DRM/smart проверяются в браузере |
| Сжатие и переименование локальных JS-идентификаторов | UglifyJS: mangle, пять проходов compress, сохранение console; проверки результата и исполнения |
| Обфускация JS | Flattening, dead code injection, string array/base64, threshold 1; внешние и доступные для преобразования inline-скрипты |
| Inline-JS | Порядок, общие переменные, обработчики событий, атрибуты script и модули проверяются в браузере |
| Минификация CSS и удаление комментариев | Восстановлено удаление обычных и специальных комментариев; комментарии внутри строк сохраняются |
| HTML-минификация и удаление комментариев | Удаляются обычные комментарии и лишние пробелы в тегах; текст, raw text и служебные маркеры сохраняются |
| Случайные классы и мусорные атрибуты | Генерация проверяется отдельно; сравниваются DOM, поведение и пиксели |
| Smart: min-файлы и компактные файлы | Проверяется побайтовое копирование JS/CSS |
| Рекурсивная обработка и ссылки на входные каталоги | Проверяются вложенные файлы и связанный сайт; циклы пропускаются с предупреждением |
| Копирование остальных ресурсов | Проверяются бинарные ресурсы и PHP |
| Sitemap для HTML/HTM/PHP и index | Проверяются генерация, пути и экранирование |
| Длинные и короткие CLI-флаги, help/version | Проверяются оба варианта; короткие флаги также проверяются в браузере |
| Монолит | В source допускается только один JS-файл; копия wsc.js с package.json запускается из временного каталога с установленными npm-зависимостями, результат проверяется в браузере |

Сохранены согласованные ограничения ради работоспособности: недоступные HTTP CSP не изменяются; локальные SRI обновляются по готовым файлам, а недоступные ссылки сохраняются с предупреждением; небезопасный вынос скриптов и изменения наблюдаемых атрибутов/классов пропускаются с предупреждением. Это не универсальная гарантия для произвольного сайта: автоматическая проверка покрывает сценарии в `browser.js`.

Запуск в установленном Edge: `$env:WSC_BROWSER_CHANNEL='msedge'; npm --prefix source test`. Сайты и снимки создаются в `%TEMP%/wsc-browser-*`.

Дополнительные браузерные сценарии проверяют обновление SRI SHA-256/384/512 и CSP (заголовки/meta), preload/CSS, ошибочный SRI, обфускацию document.write/import.meta/скриптов шаблонов на прежнем месте, точечную защиту классов/атрибутов и поддеревьев MutationObserver.
